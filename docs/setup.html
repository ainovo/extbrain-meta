Run ExtBrain on your machine.

Free and open source (AGPLv3). Five minutes, two prerequisites.

1. Prerequisites

Install Node.js 18+ and Python 3 (for the one-time NER weights): 

brew install node python3

No Homebrew? Grab the installers from nodejs.org and python.org.

Install Node.js 18+ LTS and Python 3 (for the one-time NER weights): 

winget install OpenJS.NodeJS Python.Python.3

Prefer installers? Get them from nodejs.org and python.org (tick “Add python.exe to PATH”).

2. Install & run

In a terminal (PowerShell on Windows):

git clone https://github.com/ainovo/extbrain-meta.git
cd extbrain-meta
npm install
npm run prepare:ner
npm run dev

prepare:ner downloads the one-time NER weights (~1.4GB). Then open http://localhost:5173 — the API runs on :8080.

3. Make it yours

Star or fork the repo, bring your own model keys in Settings, and your chats stay on your machine.

Star on GitHub

Prefer hosted NER/NLI over local models? Set MODAL_ANALYZE_URL and EXTBRAIN_API_SECRET in a server .env — see the repo README.
